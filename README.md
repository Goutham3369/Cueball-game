# Cueball-game
Instructions on how to play the Game:

Once the level starts there will be a board with certain number of slots

Step 1:
Use left click on mouse to select the ball that can be matched with any other same color ball.

Step 2:
Next tap on the slot that can be matched with the ball that was selected in step 1.

Step3:
Tools can used only if the progress is made, so that earning coins with the progress and buying the tools with coins earnes.


Tools:

Hint system: Tells if any match is found if the player cant find one.

Hammer system: Used to break the slots that are obstructed.

Undo : Used to go back one move (the move counts even when used undo).
